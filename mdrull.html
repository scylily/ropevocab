💡 终极写作呼吸感排版规范
专业素养
排版维度 黄金准则与示例 设计意图
中西文混排空格 汉字与半角英文、数字之间**手动保留一个半角空格**。
✅ 正确：使用 Python 处理了 200 条数据。
❌ 错误：使用Python处理了200条数据。 		避免字符过密，建立良好的视觉节奏与“呼吸感”，提升专业质感。
空行阻断机制 段落与段落、段落与代码块/表格之间，**必须保留且仅保留一个完整空行**。 防止不同 Markdown 渲染引擎（如 GitHub、Hugo）产生行内误拼接。
全小写文件命名 文件名全部小写，禁止空格，词语之间用短横线 - 链接。
✅ 正确：2024-api-v2-specs.md
❌ 错误：API Specs (Final).md 		杜绝跨操作系统（Linux 与 Windows 大小写敏感度差异）引发的死链。
