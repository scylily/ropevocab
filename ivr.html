⌨️ 播放器与打点快捷键指南

快捷键 功能描述
Ctrl + G 快速聚焦到时间跳转框（输入 5.30 回车即跳）
Ctrl + [ 设定入点 (In-Point)，画面显示已定入点 A

Ctrl + M 单点快速打卡手记 (Mark)
Space 空格 播放 / 暂停视频
← / → 基础快退 / 快进 5 秒
Ctrl + ← / → 中步长快退 / 快进 15 秒

↑ / ↓ 音量调节：增加 5% / 减少 5%

Ctrl + ↓ 减速 (-0.25x，最低 0.25x)
Ctrl + \ 一键恢复 1.0x 原速
Esc 退出当前循环播放 / 关闭弹窗

* 提示：单键（如方向键、空格）在输入框打字时会自动屏蔽，避免误触。
